# 词林 · Word Grove

> 一条向内走的路。
> 四级 + 六级大纲词汇 × 课文/真题/外刊语境 × 间隔重复 × 考试题型，一个可以离线打开、每天十分钟的英语学习平台。

《词林》以四、六级大纲词汇为词库，例句优先取自教材《Textbook Fall 2026》Unit 1–7 的课文；训练部分既有四级题型，也有课本原题与课件里的翻译/paraphrase/词汇题。课文段落按教材左侧段落编号还原，不再把编号混进正文。界面取荣格与黑塞的气质：面具、阴影、自性化——不是打怪升级，而是每天向内走一小段。

## 快速开始

1. 双击 `index.html`，用 Edge / Chrome 打开即可（无需联网、无需安装、无需构建）。
2. 首次进入「今日」，点「开始今日的 10 词」；用空格/回车翻释义，数字键 `1 / 2 / 3` 分别代表「忘记 / 模糊 / 记得」。
3. 想读课文时去「阅读」：点任意单词看中英释义、听发音；「生词高亮」默认开启并会一直保持（可手动关闭）；词卡里的「加入今日」会把它排进今天的队列。遇到不在大纲里的词，点「收进我的词林」，填词性与含义即可保存到本地（可加多条义项、自编记忆技巧、补同义词；课文例句默认带入，还能另写一句自己的例句）；之后在词卡上点「编辑我的词」随时修改。
4. 右上角可切换「夜色 / 晨光」；「旅程」里可以调每日目标、词汇范围（四级 / 六级 / 混合）、语速、系统发音人，并导出/导入进度。

> 发音由浏览器系统语音合成（Web Speech API）提供。若没有声音，先在系统里安装英语语音（Windows：设置 → 时间和语言 → 语音 → 添加英语语音），推荐使用 Edge。

### 学习闭环

```
阅读/词林点词 → 加入今日（额外队列）→ 今日闪卡（SRS）→
答错/遗忘 → 影子 → 照见/整合 → 更远的下一次复习
```

- 阅读里点过的词，可以单个「加入今日」，也可以在工具栏一次「把点过的 N 个词加入今日」。
- 今日计划会显示「今日加练」一行，这些词优先进入本组闪卡；复习后自动从队列移除。
- 影子与 SRS 是同一套记忆状态：照见成功后进入更远的复习间隔，不会回到起点。

### 学习机制（为什么这样设计）

- **间隔重复**：Leitner 盒（1/2/4/8/16 天）决定复习时间；答错回到盒 1，答对逐级后移。
- **提取练习**：先回忆再翻面；会的话题以“选择/拼写/填空”代替被动翻卡。
- **交错与微目标**：每日目标默认 10 词，复习优先；一组 2–6 分钟，降低启动成本。
- **即时反馈与解释**：每道题给出定位/搭配/词义依据；错题进影子，第二天再见。
- **双编码**：词形 + 音标 + 系统读音 + 课文语境 + 中英释义；**每个例句都可朗读**。
- **语义网络**：每张词卡列 1–3 个英文同义词，帮助把新词挂到已知词上；没有真正同义词的虚词/专名留空，不硬凑。
- **自己的词**：阅读里收进来的词存进 localStorage，进入词林「我的词」、可加今日/影子；课文例句默认带入，还可另写一句自己的例句（可留空），词卡 / 闪卡 / 影子都会显示；同义词也是可选板块，一行输入、逗号分隔多个，会显示在词卡 / 闪卡的「同义」区域；导出进度时一起带走，不依赖服务器。
- **自我决定**：可调目标、可自由漫游词林、可只做一组；不惩罚断签，只有“再走一小段”。
- **自性化叙事**：等级不是分数，是四章原型；影子不是惩罚，是尚未整合的自己。

## 数据来源与边界

- 词库：`四六级/大学英语四级词汇完整版带音标-顺序版.pdf` + `大学英语六级词汇完整版带音标-顺序版.pdf`，去重后 5546 个词条；清理了 PDF 抽词造成的 6 处残缺/重复词头（如 inser → insert、recommendati → recommendation）。
- 词义与记法：全词表 5546 个词的 `zh` 与 `mnemonic` 由 6 位撰稿人重写/补全——修正了原 PDF 里粘连、乱序、串词的中文释义；每词配 20–50 字记法。600 精讲卡保留原有精修版本。
- 同义词：全词表 5546 词补 1–3 个英文同义词（虚词/专名等无真同义词的留空）；共 5347 词有同义词，不硬凑。
- 段落还原：`tools/build_corpus.py` 按教材段落编号（1. 2. 3. …）重建段落，编号不再进入正文；Text B/C 无编号时按句群近似分组。
- 阅读文章：`2025.12/2025.06 六级真题` 的 Section C 阅读 9 篇 + `Emotion (2020)`、`JMMD (2019)` 外刊 2 篇；2026.06 真题无文字层、2025.06 第1套 OCR 质量差，已跳过。全部文章共覆盖 2346 个大纲词（四级 2067 + 六级 279）。
- 例句：教材 `book/Textbook Fall 2026 珠海校區本科英語講義.pdf`，清洗出 808 句、186 段；600 精讲词的例句均为课文原句，标注 `单元 · Text · 标题`，并配人工/模型撰写的中文译文与搭配、记法。
- 英文释义：**全词表 5546 条**，由 6 位撰稿人并行撰写；学习者词典风格，6–18 个英文词，避免循环定义。参考 Oxford 的简洁体例，但为**自行措辞**，不是照抄牛津原文；若你有授权的牛津/朗文词库文本，可替换 `build/endef_*.json` 后重跑 `tools/build_js.py`。
- 例句：已有课文/真题/外刊例句全部保留；剩余 3603 个词由 6 位撰稿人各写 1 句 8–18 词的短例句并配中文译文，全部**自行撰写、不照抄牛津/词典原文**；每个例句都有 TTS 朗读按钮。
- 自定义词：阅读未知词表单强制「单词 + 至少一条义项的含义」；「词性 + 含义」义项行可增删（一词多义），记忆技巧可自编（可留空），例句自动带入点击句（可改），其余字段可选。保存时生成 `senses[]` 与 `zh` 汇总串（供搜索/列表/出题使用），存入 `state.customWords`（localStorage），刷新不丢，随进度导出/导入；词卡上可反复编辑。旧存档在读取时自动反推出义项，不需要迁移。
- 例句翻译：**5546 个带例句的词全部有中文译文**；课文/例句译文映射 4442 句（含阅读中「在文中」句）；每个例句都有朗读按钮。
- 翻译：`四六级/四级翻译真题（202012月-2024年12月）.pdf`，真实题干 8 条（含参考译文）。
- 写作：2 条真实题干（来自课程写作材料）+ 4 条仿四级风格原创。
- 阅读/选词/匹配：从课文原文摘录，按四级题型改写设问；听力脚本为围绕课文主题原创，由 TTS 朗读。
- 新题型：三选一/15 词匹配以 U1–U4 Text A/B/C 原句挖空；翻译 4 题来自 `第四周/R&W Translation.pptx` 课件原句与译文、8 题来自 Text A 课文原句与逐句译文；paraphrase 12 题全部来自 `第八周/Paraphrasing_Review_12slides.pptx` 与 `第三周/R&W Paraphrasing.pptx` 的课件例题及参考答案。
- 课本原题：从教材 Exercise 页摘录 T/F/NG，答案据 `book/The Key to the Exercises of Text B&C.docx`；目前 6 套 35 题（Unit 1–4 Text B/C 中带 TFNG 的练习）。
- 段落为 PDF 文本重建（个别段界为程序近似）；点词查义基于词库与常见词形变化（abandoned → abandon 这类会关联），极个别不规则形式可能识别不到。
- 所有材料仅供个人学习使用；不使用任何外部 API，不上传学习数据。

## 重建数据（可选）

```powershell
# Python 使用 DSH 运行时（或任意装有 pypdf 的 Python 3）
python tools/build_corpus.py     # 教材 -> build/units.json + sentences.json
python tools/build_words.py      # 四级 + 六级词表 + 例句匹配 -> build/words.json
python tools/build_js.py         # build/*.json -> data/*.js
```

600 精讲词的例句以 `build/enrich_a_input.json` / `build/enrich_b_input.json` 为准；`build/ex_fix.json` 记录了 6 条人工替换的例句与译文。全词表英文释义分片在 `build/endef_*.json`，`tools/build_js.py` 会统一去掉个别批次带的词性前缀。

## QA

`build/qa-report.json` 记录最近一次端到端验收：**44/44 通过，无控制台错误**。覆盖：数据完整性（5546 词 / **5546 个例句全部有中文译文与朗读** / 5347 词同义词 / 11 篇真题外刊）、课文段落编号还原（无编号残留）、六级词表与词汇范围、阅读点词与「加入今日」闭环、**未知词 → 自定义词卡 → 词林 + 今日 + localStorage**、生词高亮持久、词卡同义词、六类四级题型、三选一/15 词匹配/U1–U4 翻译/paraphrase/课本原题、影子、旅程、明暗切换、刷新持久化、移动端阅读。
